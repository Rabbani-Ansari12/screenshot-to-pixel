# Project rules

These rules apply to every contributor, human or AI.

## Git

- Never rewrite published history: no force pushes, and no rebasing, amending or squashing of
  commits that are already pushed. Fix mistakes with new commits.
- Keep `main` in a working state: typecheck, tests and build must pass before pushing.

## Database (Supabase)

- All schema changes go through ordered migration files in `supabase/migrations/`
  (`supabase migration new <name>`), applied with `supabase db push`. Never change the schema
  by hand in the dashboard SQL editor.
- Every table has RLS enabled. New tables must ship with their policies in the same migration.
- Before any destructive operation on the remote project (drop table, reset, truncate,
  deleting data), stop and get explicit approval from the owner.
- Edge Functions live in `supabase/functions/`; project config in `supabase/config.toml`.

## Generated files

- Never edit generated files by hand. Regenerate them instead:
  - `src/types/database.ts` → `npm run db:types` (`supabase gen types typescript --linked`)
  - `src/routeTree.gen.ts` → regenerated by the TanStack Router plugin on `dev` / `build`

## Secrets

- Never commit secrets, tokens or keys. `.env`, `.env.local`, `supabase/.env` and
  `supabase/secrets.env` are gitignored; committed files only contain placeholders
  (`.env.example`, `supabase/secrets.placeholder.env`).
- Server-side secrets are read in Edge Functions only through `getSecret()` in
  `supabase/functions/_shared/env.ts`. See `docs/secrets.md`.
- Only `VITE_`-prefixed public values (Supabase URL and anon/publishable key) may reach browser
  code. The service-role / secret key must never be used in the frontend.

## Integrations

- AI document reading calls the Google Gemini API directly with our own key.
- WhatsApp goes through Twilio directly with our own credentials.

## Frontend

- Pages read data only through `src/services/*` (via `src/hooks/queries.ts`), never from
  `src/data` or the Supabase client directly.
- Types live in `src/types/`. Money is INR with Indian digit grouping; dates `dd MMM yyyy`,
  Asia/Kolkata.
